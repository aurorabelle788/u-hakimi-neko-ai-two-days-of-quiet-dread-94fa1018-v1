A program that writes one original code-review comment to `/output/entry.txt`:
a single line of at most 140 characters that approves a pull request while
carrying quiet existential dread.

## Run

```sh
python3 main.py
```

`OUTPUT_PATH` overrides the output location (default `/output/entry.txt`).

## Entry

> Approved. Clean diff, green tests, and the quiet sense this is the commit future-me will blame.

Python 3.13 standard library only. No network, no external files.
